Group Project | February 2026

📋 Abstract

This project implements a machine learning approach to price NASDAQ-100 futures options using real CME market data. Through iterative optimization including feature engineering, log-transformation, and Optuna hyperparameter tuning, our final XGBoost model achieves a Mean Absolute Error (MAE) of $8.44, drastically outperforming the traditional Black-76 formula (MAE: $118.36) by 93%. The trained model is deployed via a Django REST API and integrated with a React frontend, providing real-time option pricing predictions.

⚙️ Technical Implementation

Model Training

  • Algorithm: XGBoost Regressor
  • Target: Log-transformed prices (log1p)
  • Prediction: Exponential reversal (expm1)
  • Format: UBJSON binary (.ubj)
  • Loading: Pre-loaded at Django startup

Backend API

  • Framework: Django REST
  • Endpoint: POST /api/predict-option-price/
  • Format: JSON request/response
  • Validation: Comprehensive input checks
  • CORS: Configured for React frontend

💡 Understanding the 93% Improvement

⚠️ Important Context: Is 93% Realistic?

The 93% error reduction is real but somewhat artificial due to a data limitation. Here's what actually happened:

📉 In This Experiment

  • ✓ XGBoost: $8.44 MAE
  • ✓ Black-76 (with HV): $118.36 MAE
  • ✓ Improvement: 93%
  • ⚠️ Black-76 handicapped by using Historical Volatility

🏭 Real-World Deployment

  • ✓ XGBoost: ~$8-10 MAE (estimated)
  • ✓ Black-76 (with IV): ~$15-25 MAE
  • ✓ Improvement: ~40-60%
  • With proper Implied Volatility inputs

🔍 The Volatility Risk Premium Discovery

The large gap between models reveals an important financial phenomenon: the Volatility Risk Premium.

1️⃣ The Problem

Dataset lacked Implied Volatility (IV). We used Historical Volatility (HV) as a proxy, but in real markets IV ≫ HV (by 20-50%).

2️⃣ Black-76's Handicap

Using the lower HV instead of IV, Black-76 systematically underpriced options by ~$110, inflating its error.

3️⃣ ML's Discovery

XGBoost learned the risk premium from data, effectively discovering: Price = Black76(HV) + Premium

💭 The Bottom Line

If Black-76 had correct Implied Volatility inputs, we'd expect:

  • Black-76 with IV: ~$15-25 MAE
  • XGBoost: ~$8-10 MAE
  • Realistic improvement: 40-60% (still excellent!)

⚠️ For Real Deployment: The $8.44 was achieved in this experiment. In production with proper IV inputs, expect ~$8-10 MAE for XGBoost vs ~$15-25 for Black-76, giving a more realistic 40-60% improvement. Still excellent, but honest about the comparison.
